# DWEP 2026 Caregivers Support Website

Static HTML, CSS, and minimal JavaScript website for:

**Care Within and Beyond the Clinic: A Support and Psychoeducation Program for Caregivers and Families Living with Parkinson's Disease and Other Movement Disorders**

## Local Preview

```powershell
cd C:\Users\Meshell\Desktop\FastHTML\outreach
python -m http.server 8000
```

Open `http://localhost:8000`.

## Vercel Deployment Notes

Target project/domain: `caregiverssupport.vercel.app`

If this folder is pushed as the repository root, deploy normally with Vercel's static site defaults.

If this folder remains inside a larger repository, set the Vercel project **Root Directory** to:

```text
outreach
```

No build command is required.
